# Productions

**One folder per content piece** (video, major reel) — everything that made it in one place.
You recall work as "which video was that?"; this structure matches that. Name: `productions/<slug>/`.

Subfolders (use what applies):
- `outline/`   — brief, script, the actual outline
- `deck/`      — slides (HTML/CSS/JS), promo, exports
- `queries/`   — data / JS queries used to build the deck/PPT
- `giveaway/`  — the exact lead-magnet bundle shipped with the piece (PDFs/Excel)
- `publish.md` — where it was posted, links, dates

Reusable masters (a tool, reused b-roll, a book section) stay in their home folder; drop the
**exact shipped copy** here so the production is self-contained and frozen. Binaries are gitignored.
