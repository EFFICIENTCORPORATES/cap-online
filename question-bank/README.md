# Question Bank

A curated collection of questions that are **not** present in the ICAI study material — so the book complements ICAI rather than repeating it.

## Scope

- **Sources:** Past Year Questions (PYQ), Mock Test Papers (MTP), Revision Test Papers (RTP).
- **Coverage window:** last **7–10 years** (final boundary depends on the book's size).
- **Every question carries its solution.**

## Layout

```
question-bank/
├── pyq/         ← past year questions
├── mtp/         ← mock test papers
├── rtp/         ← revision test papers
└── solutions/   ← worked solutions (cross-referenced to the above)
```

Raw source PDFs live in `materials/icai-source/PYQ-MTP-RTP/` (gitignored). This folder holds the **curated, structured** versions that go into the book.
