The Core Framework

The 3K Framework

Every single class — for every chapter — follows the same three-phase structure. No exceptions. This is how each 2.5-hour session is built.

K1
Kahaani
Story — "the why before the rule"

Every concept enters through a story — not a definition.

The human brain retains events and consequences — not abstract rules. Every accounting standard has a real story: a mistake made, a consequence paid, a rule born.

Type 1 — The Arjun Universe
Arjun is every CA student. These stories are grounded in human reality — exam anxiety, the bus ride home, the conversation that changes how you see accounting.
Type 2 — The Accounting Universe
BCPL & ECPL (companies), Diya & Rolly (Accounting Doctors), Gurpreet Sir + Pranav (audit firm). Diya makes an error → Pranav catches it in audit → Gurpreet asks → concept is explained. One continuous season across all 34 chapters.
Type 3 — Real Professional Experience
IOCL (Bihar & Jharkhand, 2019–24), PPAC / Ministry of Petroleum (Additional Director — Finance), D2C CFO advisory, CA Practice. Real problems, real stakes.
⏱ 20–30 min per class
K2
Koncept
Theory — "the official rule, fully understood"

ICAI study material — chapter by chapter, no shortcuts.

  • Source is always the official ICAI Advanced Accounting study material. Definitions that matter for marks are never paraphrased.
  • Key definitions, recognition criteria, conditions, and exceptions are highlighted as we read.
  • Every concept is immediately connected to the Kahaani: "Remember when Diya did X? This is the rule that would have stopped her."
  • Real-world references woven in from professional experience: "At IOCL, this timing difference appeared every year."
  • Goal: every student can apply every principle independently under exam conditions.
⏱ 60–70 min per class
K3
Karma
Practice — "the action that gets the marks"

The most important phase. Listening alone doesn't get marks — practice does.

  • MCQ 30/30 Target: Advanced Accounts has 30 MCQ marks. The system target is 30/30. Topic-based MCQs are given daily through the online platform — relentless repetition.
  • Exam Format Practice: Every practical question is solved in exact exam format — working notes, correct headings, Schedule III structure. Practised from Day 1.
  • Error Register: Every mistake — wrong classification, missed condition, incorrect journal — is recorded in a personal Error Register. This becomes the most valuable revision tool before the exam.
  • Chapter Tests: Conducted after each chapter — MCQ + theory + practical, reviewed in the next session.
⏱ 45–60 min per class

Revision Architecture

The Layer Revision System

Every chapter is encountered three times, in three different forms, at decreasing depth. This is how long-term retention is built.

Layer 1
Full ICAI Study Material
The complete official text — every word that matters for the exam. Read and discussed in class during the Koncept phase.
When: In class, during Koncept
Layer 2
Concept Book
Chapter-wise summary of theory + explanation of each ICAI illustration. Given as the Concept Book — for revision before chapter tests and exams.
When: Self-study & before tests
Layer 3
One-Liners
The entire chapter compressed into one page — one line per topic. Read at the end of every class (5–10 min) and used to open the next class.
When: End of every class; exam revision
🧭
Layer 3 is the compass. At the end of every class, the Layer 3 summary for that day's topics is read aloud. At the start of the next class, the previous day's Layer 3 is reviewed. This creates the yesterday → today revision habit automatically — without any extra effort.

Assessment System

How Progress is Tested

Three layers of assessment — daily, chapter-wise, and full-syllabus. Each level feeds the next.

📱
Daily MCQ (Online Platform)
  • Topic-based MCQ sets available 24/7
  • Student selects any chapter or topic and gets immediate practice
  • Difficulty levels: Foundation, Standard, Advanced
  • Questions sourced from PYQ, MTP, RTP and theory bank
  • Per-topic accuracy tracked — student can see exactly where they're weak
  • Target: 30/30 MCQ marks in the CA Inter paper
📋
Chapter Tests
  • Conducted after completing each chapter or chapter group
  • Format: MCQ + 1–2 short theory questions + 1 practical (exam format)
  • Test and review in a single 2.5-hour session
  • Errors discussed in class — students update their Error Registers
  • 6 chapter tests total across the batch (at end of each phase)
🏆
ITD Tests — Full Syllabus
  • ITD = "Initial Till Date" — comprehensive cumulative tests
  • ITD Test 1: Seq 1–26 (mid-batch, ~September 2026)
  • ITD Test 2: Full syllabus (end-batch, ~October 2026)
  • Format: 3-hour paper — same pattern as the actual CA Inter exam
  • Purpose: Identify systemic gaps before the real exam, while there is still time to fix them
