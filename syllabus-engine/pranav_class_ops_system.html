Distribution & collection — offline vs online
Offline
• Printed at home / print shop before class
• Distributed at end of every class session
• Extra copies kept for absentees
• Collected next class — spot-check 8–10 copies
• Class register tracks submission per student
• Non-submitters called out by name in class
Online
• PDF shared on Telegram within 30 min of class end
• Students print or attempt digitally
• Photo submitted in Telegram group by 9 PM
• Spot-check 6–8 submissions randomly per class
• Non-submitters: name mentioned in next morning's message
• Weekly submission rate tracked and shared Saturday
