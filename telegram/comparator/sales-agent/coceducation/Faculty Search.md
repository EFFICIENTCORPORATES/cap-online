# 1LAVYA Faculty Search — COC Education

**Telegram bot:** [@Official1LavyaFacultySearchBot](https://t.me/Official1LavyaFacultySearchBot)
**Powered by:** 1LAVYA, for COC Education's own course catalog
**Status:** Live

## What this bot is for

A student can ask this bot anything about **COC Education's CA/CMA/CFM courses** —
which faculty teaches a subject, what a course costs, how classes are delivered, how
long it runs — and get a straight answer pulled from COC Education's own real course
catalog. No account, no login, no waiting for a reply from a human.

## How to use it

### 1. Just ask a question (free text)

Type what you're looking for, in plain words. The bot fuzzy-matches it against every
course's title and faculty name, so it doesn't need to be exact.

Examples:
- `Santosh Kumar accounting`
- `strategic financial management`
- `CMA foundation full course`
- `corporate and economic law`

It replies with the best-matching courses as buttons — tap one to see the full detail
card.

### 2. Or use the menu

Send `/start` any time to get the main menu:

| Button | What it does |
|---|---|
| 🔍 Search a course | Prompts you to type a subject/faculty/exam name |
| 📚 Browse by exam | Lists courses grouped under CA / CMA / CFM / Other, with paging |
| ℹ️ About COC Education | Who they are, in their own words |
| 📞 Contact / Enquiry | Real phone numbers — Call Sales, Purchase Enquiry, Tech/Login Support, WhatsApp |
| 🌐 Visit coceducation.com | Opens their homepage directly |

### 3. Reading a course card

Once you tap a course, you'll see:

- **Faculty** teaching it
- **Exam** it belongs to (CA / CMA / CFM / Other)
- **Price**, with the original MRP and discount % struck through, if any
- **Course content** (downloadable/pendrive, validity, views)
- **Number & duration of lectures**, **video language**, **doubt-solving mode**
- **Purchase options** actually available for that course (e.g. Mode of
  Distribution: D-link + Hardbook / Pendrive + Hardbook; Attempt: which exam sitting
  it's valid for)

### 4. Ready to buy?

Every course card has a **🛒 Buy Now / View Full Details** button. It's a direct
link to that exact course's real page on **coceducation.com** — the bot itself never
takes a payment; it hands you straight to COC Education's own site to complete the
purchase, exactly where the price/discount/attempt options shown in the card come
from.

## What it can't do (yet)

- It can't take a payment or place an order itself — "Buy Now" always opens
  coceducation.com.
- It only knows about COC Education's own courses — it won't answer questions about
  other institutes.
- It answers from COC Education's published catalog as of when it was last refreshed
  — for the absolute latest pricing/availability, the course's own page (via Buy Now)
  is the source of truth.
