AS 26 - Intangible
Examples: patent, copyright, software, licence, franchise, motion-picture rights, know-how.

Definition - write this in one breath

Identifiable + Non-monetary + No physical substance + Held for use / rental / administration
Not every "invisible benefit" becomes an intangible asset!

3 Core Ingredients = I + C + FEB

I - Identifiability
Separate from goodwill. Usually separable / legal rights help identify it.
C - Control
Power to obtain benefit + restrict others' access. Legal right helps, but is not compulsory.
FEB
Revenue, cost saving or other future economic benefit expected from use of asset.
Class example: Staff training gives benefit, but employees can leave → entity cannot adequately control the benefit → training cost = expense.

3-6 min

Recognition + Scope + Initial Measurement

Recognition test

Recognise intangible asset only if:
  • Item satisfies the definition (I + C + FEB).
  • Probable future economic benefits will flow.
  • Cost can be measured reliably.
Initial measurement = COST

Scope - quick memory

AS 26 does NOT deal with items specifically covered elsewhere:
  • Inventory / held for sale → AS 2 / AS 7.
  • Deferred tax asset → AS 22.
  • Leases → AS 19.
  • Goodwill from amalgamation / consolidation → relevant standards.
  • Financial assets.
But: software, start-up expenditure, advertising, training, R&D and licensing rights are examined under AS 26 rules.

Physical carrier vs intangible content

A CD/document/film may physically contain an intangible. Usually the physical carrier is insignificant, so account for the intangible substance. But if software is integral to hardware (machine cannot operate without it), treat with PPE; standalone software is generally intangible.

6-10 min

Internally Generated Intangibles - THE EXAM ZONE

R = Research → D = Development

Research Phase

EXPENSE
  • Search / investigation / obtaining new knowledge.
  • At this stage, entity cannot demonstrate a qualifying intangible.
  • If you cannot distinguish R from D → treat whole project as research.

Development Phase

CAPITALISE only after ALL tests are satisfied
  • Technical feasibility.
  • Intention to complete.
  • Ability to use / sell.
  • Probable FEB (market/usefulness).
  • Adequate technical, financial & other resources.
  • Expenditure can be measured reliably.

Timeline logic from your class notes

Past expenditure already expensed can NEVER be reinstated later.

Items normally EXPENSED

Start-up / pre-opening / preliminary activities
Training expenditure

Internally generated goodwill / brands?

Internally generated goodwill is NOT recognised because it is not an identifiable resource controlled by the entity whose cost can be measured reliably. Similar caution applies to internally generated brands, mastheads, publishing titles, customer lists and items of similar substance.
Mini example: Research ₹9 lakh → expense. On 1 July all development tests become satisfied. Later qualifying development costs ₹20 lakh → capitalise ₹20 lakh only. ₹9 lakh never comes back into the asset.
Highest-yield concept: R → expense; D → capitalise only after the recognition point
10-13 min

After Recognition - Carrying Amount + Amortisation

Subsequent measurement

Cost approach:
Cost - accumulated amortisation - accumulated impairment loss.
Revaluation:
Permitted only when fair value can be determined by reference to an active market - rare for intangibles.

Amortisation = systematic allocation

  • Start when asset is available for use.
  • Use pattern in which economic benefits are consumed.
  • If pattern cannot be reliably determined → SLM.
  • Other possible methods: diminishing balance / units of production, if they reflect consumption.
  • Review useful life + method periodically.
Useful life:
AS 26 contains a rebuttable presumption that useful life will not exceed 10 years from date available for use. Longer life needs persuasive evidence / reasons.
Residual value normally = ZERO
unless a third party is committed to buy it or an active market exists and is expected to continue.

Your class-style timeline example

Recognition decides what enters cost; "available for use" decides when amortisation starts.

Impairment

Apply impairment principles where indications exist. If carrying amount exceeds recoverable amount → recognise impairment loss. Intangibles not yet available for use require especially careful impairment consideration.
Do not confuse "capitalisation date" with "amortisation start date"
13-15 min

Closing Revision - Disposal + Disclosures + 60-sec Recall

Retirement / Disposal

  • Derecognise on disposal or when no future economic benefit is expected.
  • Gain / loss = net disposal proceeds - carrying amount.
  • Recognise gain / loss in P&L.

Key Disclosures

  • Useful lives / amortisation rates.
  • Amortisation methods.
  • Gross carrying amount + accumulated amortisation / impairment.
  • Movement / reconciliation during the period.
  • Material individual intangible details.
  • Restricted / pledged intangibles, commitments.
  • Aggregate R&D expense recognised.

6 traps to say aloud in the revision video

1. Benefit ≠ asset; control matters.
2. Research is always expensed.
3. Capitalise development only from recognition point.
4. Past expense cannot be reinstated.
5. Advertisement / training / start-up are generally expense.
6. Amortisation starts when available for use.
One-line memory: Identify → Control → FEB → Recognise → Measure cost → R/D split → Amortise → Impair → Dispose → Disclose.
