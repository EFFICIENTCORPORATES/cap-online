# Strategy Book — Pillar 1

**The Comprehensive CA Intermediate Exam Preparation Guide** — a standalone exam-strategy guide (not a teaching book) for 17–19-year-old commerce students fresh out of CPT/Foundation, that must *also* work for someone in panic mode 20 days before the exam.

> Voice: Raj Shamani / "older brother" — raw, blunt, direct, warm underneath. No gyaan. Every strategy carries a "How to Do This" block or it is cut. See `sources/SKILL-strategy-book-voice-and-tone.md`.

## What each file is

### `working/` — the active drafts

| File | What it is |
|------|-----------|
| `CA-Inter-Strategy-Book-MASTER.md` | The consolidated **working master draft** — structure + collected content, with tone, tags, and "Author Says" moments placed in position. The most current single draft; treat as the lead working copy. |
| `CA-Inter-Book-Full-Structure.md` | Complete book flow first page to last, all content collected under the correct section. Sections marked `[STRUCTURE ONLY]` still need author content. The fullest content collection. |

### `sources/` — reference, governance & memory

| File | What it is |
|------|-----------|
| `CA-Inter-General-Exam-Systems.md` | The **original source**: 25+ strategies organized by topic (Philosophy, Planning, Notes, Testing, Revision…). Everything downstream was re-architected from this. |
| `Blueprint-CA-Inter-Exam-Strategy-Guide.md` | Internal **decision log** — the debates, alternatives considered, and the "why" behind the structure. Not for student distribution. |
| `SKILL-strategy-book-structural-method.md` | Governance: the organizing logic — time-not-topic, the Routing Page, the seven buckets. Read before adding/moving any strategy. |
| `SKILL-strategy-book-voice-and-tone.md` | Governance: the voice & tone rules. Read before drafting or editing any content. |
| `summary-strategy-book-memory.md` | The full confirmed architecture: front-matter sequence, Buckets 0–6 + Emergency + AI section, 3-Layer Study Architecture, notebook/boundary systems, every locked strategy, and all 11 "Author Says" moments. |
