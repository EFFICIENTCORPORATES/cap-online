# How to Read This Book

Every small thing on these pages was put there on purpose. Before you start solving,
spend five minutes here — it will make the rest of the book far more useful to you.

---

## 1. What this book is (and isn't)

This is a **chapter-wise Question Bank** — every MTP, RTP, and PYQ descriptive/scenario
question that has ever tested a chapter, collected in one place with the official
answer, so you can practise every angle a topic has been examined from without hunting
through dozens of separate papers.

**MCQs are deliberately not included here.** They need continuous, fast, repeated
practice — a different kind of tool than a book you read and work through slowly. Use
the dedicated MCQ practice platform for that; this book is for descriptive and
scenario-based practice with full worked solutions.

---

## 2. The colour code — every box means something specific

| What you see | Colour | What it means |
|---|---|---|
| The question itself | Cream / off-white card | The question exactly as it appeared in the source paper. |
| **Answer / Solution** | Green | The official worked answer — this is what ICAI's answer key actually says (or, for descriptive answers, a faithful transcription of it). |
| **Case Scenario** (where present) | Pale purple/blue, left border | Shared background facts for a case-based question. |
| **Examiner's Comment** | Tan / orange | A **real** comment, quoted from ICAI's own official "Examiner's Comments on the Performance of the Examinees" document for that sitting. This only exists for a handful of PYQ sittings where ICAI actually published one — when you see this colour, what you're reading is ICAI's own words, not ours. |
| **Author's Note** | Pale pink | A likely pitfall for this question, written by the author (not ICAI) because no real examiner comment exists for this sitting/question. Treat it as informed guidance, not an official finding — it may not apply to every student in every case. |
| A flagged/uncertain question | Card border turns reddish | Something about this question (an arithmetic point, a source ambiguity) hasn't been independently re-verified with full confidence. Still usable for practice, just read the answer a little more critically. |

**The one rule to remember:** if the note is **tan/orange**, ICAI actually said it. If it's
**pink**, the author is telling you what usually goes wrong — an informed opinion, not
an ICAI verdict. The label on every box always tells you which one you're looking at, so
you never have to guess from colour memory alone.

## 3. What's printed on every question, and why

Each question card carries several small tools, in this order:

1. **Source line** — which paper, which question number, marks, and an **Approx Time**
   (marks × 1.8 minutes, rounded up to the nearest minute — for RTP questions where
   marks aren't stated in the source, you'll see a 10–20 minute range instead). Use this
   to pace your practice the way you'd have to pace the real exam.
2. **Topic tag** — written out in full, e.g. `M2_C5_U2 : AS 10 — Property, Plant and
   Equipment / ICAI Study Mat Topic No : 2.7`. This deliberately spells out the chapter
   code, the full chapter name, and the exact ICAI Study Material topic number(s) — so
   you always know precisely where to go back and re-read the underlying concept, not
   just which "AS number" is involved. When a question genuinely tests more than one
   chapter, you'll see both topic tags listed together.
3. **Question and Answer** — as above.
4. **Examiner's Comment / Author's Note** (§2).
5. **Student Self Notes** — a small blank white box, deliberately left empty, for your
   own two lines on this specific question — the thing *you* noticed, in your own words,
   not ours.
6. **My Notebook Ref No** — a blank space to jot down the page number in your own
   practice notebook where you've worked this question by hand. This book is the
   *reference*; your notebook is where the actual practice happens — this field is the
   bridge between the two.
7. **My Tag** — a blank space for your own label on the question: "Last-day Revision",
   "Not Important", "Easy", "Must Practice", or anything else that helps *you* triage
   what to revisit before the exam. Deliberately left freeform rather than fixed
   checkboxes, so it fits how you actually think about your own weak spots.
8. **Revision Phase completed** — three small boxes (1 / 2 / 3) to tick off as you revise
   this question again in later passes. A simple, visible record of how many times
   you've actually returned to it.

## 4. End of every chapter: "Sanjeevani Booti 2" — the Error Register

The last page of every chapter is left **intentionally blank**, with faint dotted lines,
split into two sections:

- **Section 1 — Concepts I Forgot**
- **Section 2 — Mistakes I Repeated More Than Twice**

This is not filler. Revision in the final weeks before the exam should not mean re-reading
every question again — it should mean re-reading *your own recorded mistakes*. This page
is where that record lives, chapter by chapter, in your own handwriting.

## 6. An honest note on accuracy

This is a **first edition**. It was assembled with AI assistance and reviewed carefully,
but not independently audited question-by-question at 100% certainty — every MCQ's
arithmetic was independently re-derived, but descriptive answers were checked for faithful
transcription rather than re-derived step by step. If something looks wrong, it might be —
please email the address printed at the top of each chapter so it can be corrected in the
next edition. Reporting an error you find is one of the most useful things you can do for
the students who come after you.

## 7. Coming in a future edition (not yet in this book)

Two ideas are locked in as good ones but not built yet — flagged here honestly rather
than pretended to already exist:

- **OP / PP tags** — marking, for every recurring question, which sitting is the
  *Original* version and which are later *Practice* repeats of essentially the same
  problem. This needs a proper text-similarity pass across every sitting before it can be
  trusted, so it isn't in this edition yet.
- **Short chapter names** — some chapter titles are long (e.g. the full AS 5 title). A
  future edition will use a shorter, consistent name for these in the topic tag, once
  that shortlist has been finalised.

If you notice either of these missing, that's expected for now — not an oversight.
