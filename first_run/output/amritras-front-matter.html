How to Understand this Amritras

Amrit Ras — the essence, distilled. This book is the essence of The Complete Question Bank: the same every MTP/RTP/PYQ question, chapter by chapter, but stripped down to just its coordinates and its insight — no question text, no worked answer. It exists for the days when you already know how to solve a question, and just need to be reminded that it was asked, where it sits, and what usually goes wrong with it.

Use it this way: practise from the full Question Bank Book (or your class notes) first. In the last stretch before your exam, flip through this Amritras chapter by chapter — if a card's Q.No and topic bring the question straight back to mind, tick it off; if it doesn't, that's exactly what your Self Notes space and this chapter's own Error Register are for. Colour key

Examiner’s Comment Author’s Note Flagged / Unverified

  • Examiner’s Comment (tan/orange) is a real quote from ICAI’s own published "Examiner’s Comments on the Performance of the Examinees" — ICAI’s own words.
  • Author’s Note (pale pink) is the author’s own identification of a likely pitfall where no real ICAI comment exists for that question — informed guidance, not an official finding, and may not apply in every case.
  • A flagged card (reddish border) means one detail on that question has not been independently re-verified with full confidence.

What's on every card

  • Source line — sitting, question number, and marks, so you know exactly which paper and how much it was worth.
  • Topic tag — the exact sub-topic within the chapter, so you know precisely where to go back and re-read if a card doesn't ring a bell.
  • Examiner's Comment / Author's Note — the one line of insight worth carrying into the exam hall.
  • Student Self Notes — three blank lines (one more than the main book) for your own reminder on this specific question.
  • My NB Page No / My Tag / Revision Phase — identical to the main book: where you worked this by hand, your own freeform triage word, and three tick-boxes for successive revision passes.

Topic-wise Marks Mapping

Every chapter opens with the same Topic-wise Marks Mapping table as the main book — which sub-topic was tested for how many marks, in which sitting, split by MTP / PYQ / RTP. Read this first: it tells you which part of the chapter to revise hardest.

Sanjeevani Booti — the Error Register (one page per chapter, this time)

Unlike the main book's single shared register at the back, Amritras gives each chapter its own one-page register — "Concepts I Forgot" and "Mistakes I Repeated More Than Twice" — right after that chapter's cards, so you log a mistake the moment it happens while revising that chapter, not thirty chapters later.

A few honest notes on these numbers

  • Each MTP/PYQ sitting's questions sum to 114 marks, not the paper's nominal 100 — Part II offers “answer any N of the remaining M”, and this book deliberately includes every optional question shown so you can practise all of them, not only the subset one particular sitting required.
  • RTP sittings contribute 0 marks to the total above — ICAI's own RTP documents are published without a marks-weighted answer key, not a gap in this book's tagging.
  • 763 of this edition's Common-Student-Mistakes notes are the author's own synthesized guidance (clearly labelled “Author's Note” wherever they appear), because a real ICAI Examiner's Comment document doesn't exist for every sitting yet.
