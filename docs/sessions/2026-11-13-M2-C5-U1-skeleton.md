## Tool and registry findings (not edited)
1. **`validate --fix-difficulty` crashes** (`AttributeError` at the `head = re.match(...)` line) when several cards need a Difficulty line: it replaces text inside the loop while the card positions were computed on the old text. Difficulty lines were inserted by a small script instead.
2. **Registry false entities:** ILL-1 "Historical Co" (from "Historical Cost") and ILL-3 "MT. Co" (from "MT. Cost"); the other entities (EX-2 "ABC Ltd", ILL-2 "X Co. Limited") are right. The heading rule then asks for a word that is not an entity.
3. **TYK Q16 (Sarah Limited) has no registry key**: its text sits inside the TYK Q15 block in the converted ICAI file, so the registry stops at TYK-TQ-15. A card with a `###` heading for it would fail validation, so it is written as a `####` sub-card under TQ-15. Also the finished-goods unit count (1,600) is missing from the converted question text; ICAI's solution uses it.
4. **The Difficulty check reads the first Difficulty line in a card's body**, so a `####` sub-card inside a card must not carry its own Difficulty line (the sub-card's line is written "computed by hand").
5. The ICAI scenario questions here are labelled `TYK-TQ-10` to `TYK-TQ-15` (the registry treats them as theory), not `TYK-Q`; the "is the same as" line format only accepts `TYK-Qn`.
