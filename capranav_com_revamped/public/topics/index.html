How to read a topic ID

Every topic has a short code. It is a postal address: module, then chapter, then unit, then the topic itself.

  • M = Module (ICAI splits the subject into 3 modules). C = Chapter number as printed in the Study Material. U = Unit — in the Accounting Standards chapters, one unit per Standard.
  • T2.6 = topic 6 inside Unit 2. In chapters with several units the first number repeats the unit, so a wrong ID is easy to spot. In a one-unit chapter the topic is just T and a number (for example M3-C13-U0-T4).
  • U0 means the chapter has only one unit, so there is nothing to split.
  • A page number like 5.27 means chapter 5, page 27 of that chapter in the ICAI Study Material (each chapter restarts at page 1).
  • You may see the code with hyphens (M2-C5-U2-T2.6) or underscores (M2_C5_U2_T2.6) — same thing. The underscores come from ICAI file names.

Words used on this page

Marks
A question’s marks are split equally across the topics it tests. A 14-mark question on two topics gives each 7. Both alternatives of an “OR” question are counted, because a student may need either.
Times asked
How many question parts tested the topic in the papers you selected.
Must know
Rank 1–50 for the papers you selected. Important is rank 51–100. Good to know is anything else that has been asked. Not asked yet has never appeared in those papers.
Rank
Position among all 400 topics for the papers and years you picked — it does not change when you narrow to one chapter, so a topic can still show “#7” inside a small list.
