# SEO and AI-readability (`capranav.com`)

Added 2026-09-25. Goal: search engines and AI crawlers (Google, Bing, OpenAI, Anthropic,
Perplexity, Apple and others) can read, understand and cite the site as the source for
CA Inter Advanced Accounting, while private pages and machine endpoints stay off limits.

## What is in place

| Piece | Where | Notes |
|---|---|---|
| Title, description, canonical, Open Graph, Twitter tags | `<!-- seo:start -->` block in every page | Written by `tools/apply_seo_meta.py` from its `PAGES` table. Edit the table, not the HTML |
| Structured data (JSON-LD) | Homepage: `WebSite` + `Person`; other pages: `WebPage` | Person facts limited to those stated on the site or confirmed by Pranav (ranks, first attempt, 91 marks). No employer names yet |
| `noindex` | admin, dashboard, reader | Also disallowed in robots.txt |
| `sitemap.xml` | `public/sitemap.xml` | Regenerated by `apply_seo_meta.py` (17 public URLs, clean paths) |
| `robots.txt` | `public/robots.txt` | Explicit allow for Googlebot, Bingbot, Google-Extended, GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-SearchBot, Claude-User, anthropic-ai, PerplexityBot, Perplexity-User, Applebot(-Extended), DuckDuckBot, cohere-ai, Meta-ExternalAgent, Amazonbot, YouBot. Every group disallows `/admin`, `/api/`, `/dashboard`, `/reader`. robots.txt is a courtesy: it does not stop a bad actor |
| `llms.txt` | `public/llms.txt` | Guide for AI systems: what the site is, where the useful pages are, how to attribute. A proposal, not a guarantee any crawler reads it |
| Crawler-readable HTML | `<!-- ssr:start -->` blocks on `/topics/`, `/videos/`, Must Practice | Written by `tools/build_seo_static.py`. Visible with JavaScript off, hidden (`.js .ssr`) when JavaScript runs because the interactive page shows the same content |
| Homepage hero | `index.html` | States the ranks plainly, using only facts already on the site |

Text a crawler sees without running JavaScript (before -> after): topics 0 -> 18,000
characters, Must Practice about 960 -> 17,000, videos about 450 -> 1,500.

## Re-running

```
python tools/apply_seo_meta.py       # heads + sitemap
python tools/build_seo_static.py     # crawler-readable blocks (after data changes)
npx wrangler deploy
```

Add any new public page to `PAGES` in `apply_seo_meta.py` (it will get its head block and
a sitemap entry). New analytical pages also need the "Powered by 1LAVYA" footer.

## Cloudflare and the AI crawlers (2026-09-25)

Earlier the same day, a test with each crawler's user-agent returned `403 Your request was blocked.` for GPTBot,
ClaudeBot, anthropic-ai, Amazonbot, cohere-ai, CCBot and Bytespider (search/user bots such as OAI-SearchBot,
Claude-SearchBot and Perplexity were allowed). Pranav then confirmed he had not set a block deliberately and
applied Cloudflare's "allow" list; a retest an hour later returned 200 for every crawler user-agent. Note that
these tests use the crawler's *name*, not its real IP: Cloudflare identifies real crawlers by IP, so a test from
another machine only shows how the *claimed* name is treated. Any remaining failed GPT requests in the Cloudflare
dashboard are most likely (a) requests from before the change, (b) our own test requests, which carried those
names, (c) impostors using GPTBot's name, or (d) real GPTBot hitting missing URLs. Check in the dashboard with
User Agent contains GPTBot, grouped by status code, path and "verified bot". A Python-urllib user-agent still gets
403 (Cloudflare's browser integrity check); curl, wget and python-requests get 200.
